# Documentation synthesis

1. Use validated finding records as the canonical layer.
2. Check specialist document IDs against canonical records and report missing or unknown references.
3. Deduplicate equivalent findings without allowing a model suggestion to supersede deterministic evidence.
4. Group shared rule signatures as root-cause hypotheses, not proven organizational causes.
5. Flag neighboring performance and safety findings that may interact; retrieve more context when needed.
6. Render Markdown from canonical data and preserve all applicability limitations.

Never fabricate business logic, benchmarks or external citations to fill a template. See [architecture](../../../docs/architecture.md).
